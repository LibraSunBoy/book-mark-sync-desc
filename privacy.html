隐私政策

适用版本：书签坞 1.0.0（Chrome / Edge / Firefox 扩展） · 生效日期：2026-11-07

核心承诺：我们不收集书签、不收集网址、不记录浏览行为、不做任何遥测。 书签数据只会在你的浏览器与你选择的存储（默认是你自己的 GitHub Gist）之间传输。

1. 我们是谁

书签坞（BookmarkDock，下称"本扩展"）是一个开源的浏览器书签同步扩展。 本扩展没有自建后端服务器，开发者不接收、不存储、也无法读取用户的任何书签数据。

2. 我们不收集什么

  • 不收集书签的标题、网址、文件夹结构或数量；
  • 不收集浏览历史、当前打开的标签页、表单内容或搜索记录；
  • 不收集设备标识、IP 地址、位置、崩溃日志或使用统计；
  • 不投放广告，不向任何第三方出售或共享数据；
  • 不包含任何分析、埋点、A/B 测试或远程配置 SDK。

3. 书签数据去了哪里

本扩展采用 BYO 存储（Bring Your Own Storage）： 你在配置向导里连接的存储位置就是唯一的数据目的地。

  • 当前版本支持 GitHub Gist。同步文件通过 GitHub 官方 API 直接写入 你在自己账号下创建（或授权创建）的 Gist。
  • 文件权限由 GitHub 决定；如果你创建的是 secret gist，只有你知道链接的人可以访问。
  • 开发者没有你的 GitHub Token，也没有该 Gist 的访问权限，因此无法读取其中的书签。
  • 如果启用端到端加密，写入 Gist 的内容是 AES-256-GCM 密文；密码只保存在本机内存中。

4. 本机保存的数据

为了完成同步与恢复，本扩展会在你的浏览器本地保存以下数据：

位置 内容 用途
storage.local 设置、GitHub 访问令牌、Gist ID、License 激活信息 让你不必每次同步都重新授权
IndexedDB 同步状态、书签 ID 映射、快照、回收站、冲突记录 撤销、恢复、跨浏览器 ID 对应
storage.session 端到端加密的解锁材料（仅当前浏览器会话） 关闭浏览器后自动清除

这些数据不会离开你的设备，除非它们属于"要同步的书签内容"，并且你已连接存储。 卸载扩展会删除扩展的本地存储。

5. 网络请求清单

本扩展只会向以下域名发起请求，且都由你的操作触发：

域名 何时 内容
api.github.com
gist.githubusercontent.com		 你连接 GitHub 后，同步时 读写你自己的 Gist / 校验 Token
github.com GitHub Device Flow 授权、打开管理页时 OAuth 授权流程
api.lemonsqueezy.com 仅当你点击「激活」「刷新 License」时 校验 License Key 与设备数

没有其他网络请求。扩展不加载远程代码，不下载远程脚本，不使用 CDN。 上述网络权限默认未授予，会在你实际使用时按需申请。

6. 权限说明

权限 为什么需要
bookmarks 读取与写入书签，这是同步功能的全部内容。
storage 保存设置、同步状态、快照与本地映射。
alarms 定时轮询远端，实现自动同步。
notifications 同步失败或需要确认删除时提醒你。
可选主机权限 仅在你连接 GitHub / 激活 License 时按需申请对应域名。

7. 第三方服务

  • GitHub：存储与授权由 GitHub 提供，适用 GitHub 隐私声明。
  • Lemon Squeezy：仅在你主动激活付费 License 时，将 License Key 与设备标识发送给 Lemon Squeezy 完成校验，适用 Lemon Squeezy 隐私政策。 v1.0 不启用付费闸门，正常使用不会触发该请求。

8. 数据保留与删除

  • 本地数据：卸载扩展即删除；也可在浏览器扩展设置中清除存储。
  • 远端书签：由你保存在自己的 Gist 中，随时可在 GitHub 删除。
  • 开发者侧：不保存任何用户数据，因此没有"申请删除"流程。

9. 儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集儿童数据（实际上不收集任何人的数据）。

10. 政策变更

如果未来引入新的存储后端或网络请求，我们会在本页面更新，并在扩展更新日志中说明。 任何会改变"数据去向"的变更都会在生效前明确提示。

11. 联系方式

隐私相关问题请通过项目仓库提交 Issue： Gitee Issues。 邮箱：dev@bookmarkdock.app。

English summary

BookmarkDock is an open-source bookmark sync extension with no backend server. We do not collect bookmarks, URLs, browsing history, analytics, or telemetry. Your bookmarks are written directly to the storage you configure (currently your own GitHub Gist), using your own credentials. The only network requests are to api.github.com / gist.githubusercontent.com (sync), github.com (OAuth device flow), and api.lemonsqueezy.com (only when you activate a paid license). You can delete all local data by uninstalling the extension, and delete remote data from your own Gist. Contact: dev@bookmarkdock.app.
