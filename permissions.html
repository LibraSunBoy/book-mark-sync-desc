权限说明

对应扩展版本 1.0.0 · 审核与用户可见说明一致

单一用途

书签坞的唯一用途是：在用户自己的存储位置之间同步浏览器书签。 扩展不修改网页、不拦截请求、不读取页面内容。

必需权限

权限 用途 用户在哪里感知
bookmarks 读取书签树、监听增删改、在同步时写入书签。 预览、同步、导入、恢复、撤销书签时。
storage 保存设置、凭据、同步状态、快照、回收站与 ID 映射。 安装后即需要；不涉及网页数据。
alarms 按设定间隔唤醒后台，轮询远端变化。 设置里的"同步间隔"。
notifications 同步失败、删除熔断需要确认时发系统通知。 出现需要用户处理的错误时。

可选主机权限（按需申请）

这些权限默认不授予，只在你点击"连接 GitHub"或"激活 License"时， 由浏览器弹出授权框，你同意后才生效。拒绝不影响书签本地管理。

域名 用途 触发动作
https://api.github.com/* 校验 Token、读写 Gist、GitHub Device Flow。 连接 GitHub / 同步
https://github.com/* Device Flow 授权页、打开 Gist 管理页。 连接 GitHub
https://gist.githubusercontent.com/* 读取 Gist 原始内容。 同步
https://*.githubusercontent.com/* GitHub 内容 CDN 重定向。 同步
https://api.lemonsqueezy.com/* License 激活、校验、释放设备。 点击"激活 / 刷新"

不需要的权限

  • tabs / activeTab / scripting：不同步标签页，不注入脚本，不修改网页。
  • history：不读取浏览历史。
  • webRequest / proxy：不拦截或修改任何网络请求。
  • cookies：不使用 Cookie。
  • <all_urls>：不需要访问任意网站。

远程代码

本扩展不加载、不执行任何远程代码。所有 JavaScript 都打包在安装包内， 不使用 eval、new Function 或动态 <script> 注入。

数据使用声明

  • 不收集个人身份信息、健康、财务、认证、通信、位置、网页浏览记录；
  • 书签内容仅写入用户自己配置的存储，不发送给开发者；
  • 不向第三方出售数据，不用于广告，不用于信用评估；
  • 零遥测：不包含任何统计或崩溃上报 SDK。
